# Aerial 默认焦点位置测试版

基于 1.99（146），包名 `app.orchard.tv`，版本 `1.99-focus1`（147）。

唯一功能改动：在桌面图标的长按菜单里增加「默认焦点位置：开 / 关」。个性化设置没有新增入口。

- 默认第一排中间的位置开启：五格时是第三格；偶数格时是靠左的中间格。
- 长按希望选中的位置上的图标，将「默认焦点位置」打开，其他位置自动关闭；按确定键即可切换。
- 选择记录为行、列，不记录任何应用名或包名。以后换软件占据该格，焦点仍停在原格。
- 在已开启的位置关闭此项，则恢复 Aerial 原来的默认焦点规则。
- 开机进入 Aerial、重新创建桌面、按主页键、从其他应用返回时使用选定位置。
- 只选中、不启动应用；「开机时打开」、遥控器操作、选中框、壁纸和排列功能保持原样。
- 文件夹内的应用菜单不显示此项，避免把文件夹内的位置误当桌面位置；桌面的文件夹图标可以选。
- 所选格子后来变空时采用原有焦点回退策略，不打开或移动应用。

## 安装前

这是源码重新编译的 release 测试包，签名与用户提供的原 APK 不同。没有原作者签名密钥，不能覆盖原版。不要为了安装它直接卸载原版或清除数据；原有排列、壁纸和授权需先保留。签名兼容问题与本次焦点功能是两件事。

包名按要求保持 `app.orchard.tv`，没有改成之前的小米适配包 `com.ts.launcher`，也没有改动 HOME 白名单、系统组件或守护策略。

同名 `.dm` 是 Android 9–11 安装优化元数据；直接用文件管理器安装 APK 不影响焦点功能测试。

## 验证边界

CI 对 Android 10 环境下的 Compose 焦点与遥控器事件、位置持久化、菜单开关和已有单元测试进行验证；完整 lint 与未修改的基线比较。以相应工作流实际结果为准。

尚未连接用户的电视；真实断电开机、固件抢桌面、实体遥控器效果仍需真机确认，不将模拟测试称为真机通过。
